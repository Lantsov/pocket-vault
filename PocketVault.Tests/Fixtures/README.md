# Контейнер предыдущей версии

`v1-container.base64` создан исходным `VaultFormat.cs` из коммита `661c57c` до миграции WinForms → WPF. Хранится в Base64, чтобы не попадать под правило игнорирования пользовательских `.pvlt`.

- Имя внутри контейнера: `наследие.txt`.
- Данные UTF-8: `PocketVault v1 — совместимость формата.` и перевод строки LF.
- Пароль: `Пароль совместимости 2026`.

Это публичные тестовые данные. Фикстура не пересоздаётся тестами и проверяет чтение ранее созданного контейнера через WPF и Core.

- Имя: `v1.1.0-example.txt`.
