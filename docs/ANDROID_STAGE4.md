# PocketVault Android — отчёт этапа 4

Проверено 26 октября 2026 года. **Android 1.0.0 ещё не готов к выпуску:**
ключ владельца не предоставлен и не создавался; подписанного им APK нет.
Сборка и инструкция интерактивного создания ключа подготовлены в [ANDROID.md](ANDROID.md).
Windows 1.1.1 и его опубликованные файлы не изменялись; формат остаётся v1.

## Устройство и инструменты

Физический Poco X6 Pro не подключён. Все текущие Android runtime-проверки
выполнены на AVD `Medium_Phone_API_36.0`, Android 16 / API 36, x86_64,
`emulator-5554`, Emulator 36.2.12 / WHPX. Это **не** проверка физического телефона,
ARM64 runtime или минимального API 29.

.NET SDK 10.0.403, runtime 10.0.14, MAUI 10.0.0,
Android SDK pack 36.1.2, platform 36, build-tools 36.0.0, JDK 21.0.11.

Release без ключа владельца завершается до сборки/подписи с понятной ошибкой.

## Приватность и ограничения готовности

В итоговом Release нет INTERNET, READ/WRITE_EXTERNAL_STORAGE и
MANAGE_EXTERNAL_STORAGE. Backup отключён. Экспортирован основной launcher
для MAIN и узкого VIEW; AndroidX ProfileInstallReceiver защищён системным
разрешением DUMP. MAUI добавляет свои служебные компоненты, включая
неэкспортируемый KeepAliveService; фоновой синхронизации в приложении нет.
Пароли, plaintext и URI приложение не сохраняет в preferences/cache/логах.
Managed strings и копии клавиатуры гарантированно стереть нельзя.

Ограничения: 32 МиБ, обработка в памяти, отсутствие отмены криптографии,
восстановления пароля, безопасного удаления и независимого аудита.
DocumentsProvider может оставить частичный документ при прерывании или запрете
удаления. Синтетический OOM не воспроизводит Android low-memory killer.
Сторонние облачные провайдеры, USB Poco, API 29 и ARM64 runtime не проверены.
Общий MIME файлового менеджера требует открытия через кнопку приложения.

Код подготовлен к review. Для завершения выпуска нужны интерактивно созданный
ключ владельца, подпись и проверка готового ARM64 APK, установка и проверка
на целевом телефоне. Keystore и пароли нужно сохранить вне Git для обновлений.
PR автоматически не сливается, GitHub Release автоматически не создаётся.

Для тестовой установки на Poco можно использовать только явно помеченный Debug ARM64
из `dist/android/debug/android-arm64/`; это development key, не выпуск Android 1.0.0.

[контейнер из ACTION_VIEW](images/android-stage4-decrypt.png). Синтетические данные,
