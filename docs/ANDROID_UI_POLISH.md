# Android 1.0.0 — интерфейс, RU/EN и Iosevka Slab

27 октября 2026 года. Изменения относятся к Android UI, локализации и шрифтам.
Core, формат `.pvlt`, AES-256-GCM, PBKDF2, лимит 32 МиБ, SAF и Windows не изменены.

## Типографика и сетка

Встроены три официальных неизменённых TTF из Iosevka Slab **34.9.1**:
Regular 400, Medium 500, Bold 700. Шрифты зарегистрированы в `MauiProgram`;
общие стили находятся в `App.xaml`. Название — 24 sp Bold, заголовки — 19 sp
Medium, основной текст — 15–16 sp, подписи — 13 sp, технические метки — 12 sp.
Системный размер текста сохраняется, масштабирование вниз не применяется.

У всех трёх файлов проверены полные английский и русский алфавиты, включая Ё/ё:
пропущенных символов нет; `isFixedPitch = 1`, ширина каждого символа — 500/1000 em.
Debug-аудит на Android сравнивает фактический `TextView.Typeface` с результатом
MAUI `IFontManager` для выбранного семейства, а также проверяет наличие кириллицы
и платформенную маскировку паролей. Тексты полей, пароли и URI в аудит не записываются.

Происхождение, контрольные суммы и [лицензия OFL](../PocketVault.Android/Resources/Fonts/README.md)
сохранены рядом со шрифтами. Полный исходный текст OFL доступен офлайн в настройках.
Полный юридический текст MIT оставлен на английском без изменений.

Шапка, карточки, поля и основная кнопка используют общую ширину, внешние отступы
24 dp, внутренние 16 dp, интервалы 8/12/16/24 dp. Интерактивные области — от 48 dp.
Карточка выбора стала компактнее; длинное имя ограничено двумя строками с многоточием,
полное имя остаётся доступным accessibility. Кнопки допускают перенос текста.
На узком экране с крупным текстом настройки переходят на вторую строку шапки,
чтобы название PocketVault оставалось целым. Обе страницы прокручиваются.
Видимая область главной формы дополнительно ограничивается рамкой окна при
открытой клавиатуре: активное поле прокручивается над IME, а основная операция
доступна прокруткой без закрытия клавиатуры. Наблюдатель размеров снимается при
уходе со страницы; пароли и файловые операции в нём не обрабатываются.

## Локализация

Строки находятся в `Resources/Localization/AppResources.resx` (English) и
`AppResources.ru.resx` (русский); ключи и параметры форматирования совпадают.
`LocalizationManager` обновляет XAML bindings и динамические статусы сразу,
включая уже открытые страницы. Числа и единицы форматируются выбранной культурой.

В настройках доступны **System / Системный**, **Русский**, **English**.
Выбор хранится в Preferences под ключом `ui.language`. По умолчанию читается
системный Android locale: `ru` → русский, остальные языки → English.
Ручное переключение не требует перезапуска. При смене языка поля пароля очищаются
и снова маскируются. Пароли не переносятся в Preferences или модель локализации.
Исходные правила очистки при уходе с экрана/в фон сохранены.

Исключения Core и файловых сервисов не переводятся разбором текста: UI выбирает
ресурс по типу ошибки и контексту операции. Ошибка аутентификации получает отдельное
сообщение; ошибка записи предупреждает проверить неполный файл, если он остался.
Технические имена и содержимое документов не переводятся.
Системные SAF-диалоги используют язык и шрифт Android/провайдера, как прежде.

Снимки получены на Android runtime эмулятора Android 10 / API 29, x86_64,

`demo_screenshots=true`, только синтетические данные. `FLAG_SECURE` и код

скрытии и последовательной смене всех четырёх размеров. Доступная основная
кнопка проверена по пикселю фона: `#F4F4F4`; её visual states независимы от
второстепенных кнопок.

## Сборки и границы проверки

ARM64 Release собирается существующим `scripts/build-android.ps1 -Configuration Release
-Unsigned -RuntimeIdentifier android-arm64 -SkipWindowsTests`. Пакет проверяется
скриптом по ApplicationId, версии, API, ABI и выравниванию.
Debug x64 используется для реальных снимков; отдельный Release x64 — для проверки
локализации после XAML-компиляции, trimming и AOT с временной development-подписью.

Результаты визуальной матрицы и краткой регрессии фиксируются в
[публичном отчёте](verification/android-ui-polish.json).
Локальные полные снимки матрицы и безопасные отчёты шрифтов:
`dist/android/ui-polish/`.

Краткая регрессия на Android runtime: **11/11** существующих crypto smoke-проверок,
включая создание/восстановление контейнера и наследуемые fixtures. Широкий повтор
файловых провайдеров, больших файлов и Windows-проверок в эту UI-задачу не входил.
Ошибка неверного пароля проверена на English и переведена в уже открытом статусе
на русский без повторного запуска операции. Шрифты совпали с ожидаемыми во всех
44 проверенных нативных текстовых контролах главной страницы и настроек.
Итоговый development-signed Release x64 после trimming/AOT запускается на API 29:
RU/EN переключаются сразу, ручной выбор и System переживают перезапуск, System
при английском языке Android показывает English. В окне Release подтверждён
флаг `SECURE` даже при передаче Debug-only extra `demo_screenshots=true`.
Критичных визуальных недостатков в проверенных сценариях не обнаружено.

Ранее [проверенный подписанный владельцем APK](ANDROID_RELEASE_1.0.0.md)
сохранён без изменений. Его хэш и физическая проверка относятся к предыдущему
интерфейсу. Обновлённый интерфейс потребует новой сборки с тем же ключом владельца
перед распространением. В этой UI-задаче постоянный ключ и пароли не используются,
новый подписанный выпуск не создаётся. PR #3 не сливается, GitHub Release не публикуется.
